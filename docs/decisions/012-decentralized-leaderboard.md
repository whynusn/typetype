# ADR-012: 去中心化排行榜（本地优先 + 可选联邦 board）

<!-- 状态: proposed | 决策日期: 2026-08-07 -->

> 从 ADR-011 拆出的独立排期项。背景：typetype 拟舍弃 typetype-server 中心化排行榜/账号体系，改为本地优先 + 可选联邦 board。

## 背景

typetype-server 承载 text_id 解析、成绩提交、排行榜、账号（JWT）。去中心化目标下：

1. 成绩与历史是本地用户数据，不应依赖中心服务。
2. 排行榜的社交属性弱，中心化代价高（账号体系、防作弊、运维）。
3. 联邦 board 可作为可选增强，不阻塞主线。

## 决策（草案）

1. **本地记分板为默认**：成绩、历史、统计全部本地持久化；`text_id` 用内容 hash（已有 `text_id_from_content`）。
2. **可选联邦 board**：独立轻协议 `ott-board`；提交 = `{content_hash, score, replay_hash, timestamp, signature}`，签名用用户 Ed25519 私钥。
3. **身份无账号**：匿名 ID = 公钥指纹；无密码、无中心数据库；跨 board 实例可迁移。
4. **TOFU**：客户端首次连接 board 时固定其公钥，变更显式告警。
5. **防作弊弱保证**：签名防篡改 + 回放摘要可验；真人代打无法阻止，UI 明示信任边界。
6. **UI 迁移**：极速杯等入口切 OTT 源 + 本地记分板；联邦 board 为可选配置。

## 影响与排期

- 独立于 ADR-011 主线，可并行执行。
- 任务明细：本地记分板数据模型与持久化；ott-board 协议草案（`docs/designs/ott-board.md`）；身份模块；UI 迁移。
- 依赖：无（可先行），签名体系成熟后可复用 ADR-011 的密钥管理。

## 待确认

1. 联邦 board 是否需要防作弊更强的方案（如回放验证服务、成绩匿名可信证明）。
2. board 实例的运营方与收稿策略（官方自托管 vs 社区自托管）。
